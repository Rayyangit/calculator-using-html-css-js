# Calculator Web Application

This repository contains the source code for a **Calculator** web application built using **HTML**, **CSS**, and **JavaScript**. The calculator supports basic arithmetic operations with a clean and user-friendly interface.

## Features

- **Basic Arithmetic Operations**: Perform addition, subtraction, multiplication, and division.
- **Responsive Design**: The calculator is designed to be responsive, making it usable on both mobile and desktop devices.
- **Interactive UI**: Buttons react visually to user interaction for a better user experience.
- **Real-Time Calculations**: Results are computed instantly as you enter values and operators.

## Technologies Used

- **HTML5**: Structuring the calculator interface.
- **CSS3**: Styling the buttons, display screen, and layout.
- **JavaScript**: Handling the functionality for the calculations, button events, and display updates.

## How to Run

1. Clone the repository:
    ```bash
    git clone https://github.com/your-username/calculator-app.git
    ```

2. Open `index.html` in your web browser to start using the calculator.
